## 🚀 Overview

**AuthoIPTV** is a modern, feature-rich **desktop IPTV player** built with **Electron**, designed for smooth, flexible, and secure streaming.

It supports **M3U playlists, EPG integration, custom authorization headers, DASH & DRM (ClearKey)**, and advanced channel navigation — all wrapped in a clean **Material UI** interface.

AuthoIPTV is **player-only** software, giving users full control over their own playlists and streams.

---

## ✨ Key Features

### 📺 Playback & Streaming
- **M3U Playlist Support** — Load and stream IPTV playlists effortlessly
- **Single Stream Playback** — Play direct stream URLs with headers & DRM
- **HLS Playback** — Powered by [hls.js](https://github.com/video-dev/hls.js)
- **DASH + DRM (ClearKey)** — Powered by [Shaka Player](https://github.com/shaka-project/shaka-player)
- **Full-Screen Playback** — Immersive viewing experience
- **Multi-Audio Track Selection** — Choose preferred audio streams

### 📚 Playlist & Channel Management
- **Multiple Playlists** — Add, edit, and organize playlists
- **Auto Playlist Updates** — Keep playlists refreshed automatically
- **Playlist & Channel Search** — Quickly find channels or content
- **JSON Playlist Support** — Load playlists in JSON format
- **Channel Navigation Panel** — Fast browsing and switching

### 🔐 Advanced Capabilities
- **Custom Authorization Headers** — For protected IPTV streams
- **Custom User-Agent Support** — Control how playlists are fetched
- **EPG (Electronic Program Guide)** — Program schedules from providers
- **Keyboard Shortcuts** — Fast navigation and playback control

### 🎨 UI & Platform
- **Material UI Design** — Clean, modern interface
- **Light & Dark Mode** — Comfortable viewing anytime
- **Cross-Platform** — Windows, macOS, and Linux
- **Standalone Desktop App** — No browser dependency
